UploadNPlay API

Base URL:

https://rldidvwcylirjyfktvtg.supabase.co/functions/v1/uploadnplay-api
GET /games/:gameId

Returns public information for an approved game.

GET /games/:gameId/achievements

Returns enabled achievements and, when an authenticated player token is supplied, that player's unlocked state.

GET /me

Returns the authenticated UploadNPlay player from a bearer player/session token.

POST /games/:gameId/achievements/:achievementKey/unlock

Client unlock. Send a player bearer token. This only works when the achievement is marked client-unlockable.

Authorization: Bearer YOUR_PLAYER_TOKEN
POST /games/:gameId/achievements/:achievementKey/unlock

Server-only unlock. Send the secret in the header. Never expose this value to browser code.

x-api-secret: YOUR_SERVER_SECRET
Content-Type: application/json

{"playerId":"UPLOADNPLAY_PLAYER_ID"}

Credentials

Each game can have a public key and a separate server secret. The server secret is stored only as a hash and is shown once when generated or rotated.

Example server unlock

await fetch('https://rldidvwcylirjyfktvtg.supabase.co/functions/v1/uploadnplay-api/games/GAME_ID/achievements/first-win/unlock', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-secret': process.env.UPLOADNPLAY_API_SECRET
  },
  body: JSON.stringify({ playerId: playerId })
});
