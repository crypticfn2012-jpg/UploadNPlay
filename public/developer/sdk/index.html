UploadNPlay SDK

Use the browser SDK to connect an HTML5 game to UploadNPlay achievements and player data.

Install

<script src="https://crypticfn2012-jpg.github.io/UploadNPlay/sdk/uploadnplay.js"></script>
<script>
const unp = UploadNPlay.init({
  gameId: 'YOUR_GAME_ID',
  publicKey: 'YOUR_PUBLIC_KEY'
});
</script>

Game information

const game = await unp.getGame();
console.log(game.game.title);

Player

const player = await unp.getPlayer();
console.log(player?.player);

For games launched through UploadNPlay, the platform can provide a short-lived player token to the game. A missing token means the player is not signed in.

Achievements

const achievements = await unp.getAchievements();

await unp.unlockAchievement('first-win');

Client unlocks only work for achievements that the developer marked as client-unlockable. Server-only achievements must be unlocked by a game backend with the server API secret.

Never ship the server secret

The public key is safe to include in a browser game. The server secret is not. Keep the server secret in your backend environment and send it only as the x-api-secret header to the UploadNPlay server API.
